# 2026-07-18 · 故事书设计改进

## 三个核心更新

### 1️⃣ 纸张真实感强化
页面现在像真实翻开的书籍。

**页脊效果**
- 左页右侧：深度渐变阴影，从黑色渐淡
- 右页左侧：对称的渐变，模拟纸张厚度
- 效果通过 `::after` 伪元素和渐变创建

**页边内凹**
```css
box-shadow:
  inset 0 0 12px 1px rgba(0,0,0,0.4),    /* 内凹深度 */
  inset 12px 0 0 -8px rgba(0,0,0,0.2),   /* 左内凹 */
  inset -8px 0 0 -8px rgba(0,0,0,0.15)   /* 右内凹 */
```

**背景质感**
- 从单调渐变改为 135deg 对角线渐变
- 颜色更深：rgba(18,18,18,0.99)
- 增强了印刷品质感

### 2️⃣ 排版节奏压紧 (章节风格)

让文本布局像正式的学术文档或设定集。

**空间压缩**
| 项目 | 原值 | 新值 | 变化 |
|------|------|------|------|
| 元素 gap | 12px | 6px | -50% |
| 列表项间距 | 8px | 4px | -50% |
| 正文字号 | 0.96rem | 0.92rem | -4% |
| 行高 | 1.95 | 1.8 | -7.7% |
| 标题 | 2rem | 1.72rem | -14% |

**效果**
- 更像学术论文的排版密度
- 不显得拥挤，但更紧凑
- 强化设定集感而非展示页感

### 3️⃣ 引用块克制化

从"突出展示"改为"融入整体"。

**Quote 块**
```css
/* 原 */
border-left: 2px solid rgba(255,255,255,0.34);
background: rgba(255,255,255,0.045);
font-size: 1rem;

/* 新 */
border-left: 1px solid rgba(255,255,255,0.24);
background: rgba(255,255,255,0.02);
font-size: 0.91rem;
```

**Note 块**
- 背景几乎不可见：rgba(0,0,0,0.008)
- 边框改为 1px，低调
- 字号缩小到 0.85rem

**Section 块**
- 标题改为 sans-serif（不再用 serif）
- 背景极简：rgba(255,255,255,0.015)
- padding 从 16px → 12px

### 整体对比

| 维度 | 改前 | 改后 |
|------|------|------|
| **气质** | 展示页 / 博客风 | 设定集 / 学术风 |
| **纸张感** | 平面现代 | 立体印刷 |
| **排版** | 宽松通俗 | 紧凑正式 |
| **强调** | 多样鲜明 | 克制统一 |
| **阅读感** | 浏览式 | 深读式 |

## 技术细节

### CSS 变量变更
- 页面 padding：`34px 30px 28px` → `52px 46px 44px`
- box-shadow：新增 inset 多层叠加，创建 3D 纸张感
- 页脊伪元素：`::after` 宽度 26px → 32px，更明显

### 字体调整
- 依然使用：Noto Serif SC (标题) + Noto Sans SC (正文)
- Space Mono (代码 / 标签)
- 但字号和行高全面调整，让密度更高

### 响应式适配
- 平板：padding 40px 36px 32px（保持比例）
- 手机：padding 18px（保持可读性）
- 页脊宽度和阴影深度自动缩放

## 后续延伸

这次更新为后续几个方向铺路：

1. **逐页翻阅感** - 已有页脊，可后续加翻页动画
2. **书签功能** - 纸质感强化后，可加书签 UI
3. **页码装饰** - 现在已有底部空间，可加古典页码风格
4. **边距注记** - 纸张内凹后，可在边距放评注框
