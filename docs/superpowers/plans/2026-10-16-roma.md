# roma 香气卡片生成器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个本地 web 工作台：输入香味描述 → LLM 一次调用出结构化信息 → 生成正反两面（Riso / ASCII）的香气卡片，翻面切换，一键存当前面 PNG。

**Architecture:** 原生 Node http 服务（对齐 motionlab），server 拆 llm/prompt/parse 各带测试，`/generate` 一次 LLM 调用返回结构化 JSON。前端原生 JS：ascii.js 排等宽、riso.js 出套色半调 SVG，卡片 CSS 3D 翻面，PNG 走浏览器 canvas 导出。放 `agents/roma/`，补 `launch` 自动进 Hub。

**Tech Stack:** Node.js（原生 http）、vitest、原生前端、网关 LLM（OpenAI 兼容）。

**Spec:** `docs/superpowers/specs/2026-10-16-roma-design.md`

## Global Constraints

- 服务只监听 `127.0.0.1`，端口 4322（避开 motionlab 4321）。
- 复用网关：`GATEWAY_API_KEY` / `GATEWAY_BASE_URL`，`.env` 启动时读入、不覆盖已设。
- 不读取/不回显 `.env` 内容。
- 用户输入只作为 LLM 提示词内容，绝不进入 shell / 文件路径拼接。
- 不展示调用花费 / token 估算（无 cost 模块）。
- 渲染器不引后端图像库；PNG 走浏览器 canvas。
- 不引前端框架。
- `AGENT_DIR` 从 `server/` 向上定位，不写死绝对路径。
- 整体视觉走纸感 zine 风（对齐 posterdesigner）：纸底 `#f4f1ea`、墨黑 `#1a1a1a`、灰调 `#8a8378`、面板布局。Task 6/7 的视觉需整合转转提供的卡片/排版参考后再定稿。

## Review Focus

- **LLM 返回非合法 JSON**（模型包了 ```json 代码块 / 前后有解释文字）：parse 必须能剥壳提取 JSON，彻底失败时抛可读错误，不抛未捕获异常。（Task 2 覆盖）
- **LLM JSON 缺字段**（缺 ascii / palette / notes）：parse 兜底——ascii 缺用占位、palette 缺给中性油墨色板、notes 缺给空结构，仍能出卡。（Task 2 覆盖）
- **网关 key 缺失 / 401**：`/generate` 返回可读错误（提示去填 .env），不崩进程。（Task 4 覆盖）
- **空输入 / 纯空白输入**：`/generate` 返回 400 可读错误，不调 LLM 白烧 token。（Task 4 覆盖）
- **palette 含非法/非 hex 颜色**：riso 渲染器映射到最近油墨色时跳过非法值、至少保留一个安全色，不产出坏 SVG。（Task 6 覆盖）

- [ ] **Step 5: 写 `agents/roma/server/parse.js`**

```js
const DEFAULT_PALETTE = ['#FF48B0', '#0078BF', '#FFE800'];

function stripFence(text) {
  const fence = text.match(/```(?:json)?\s*([\s\S]*?)```/i);
  if (fence) return fence[1];
  const first = text.indexOf('{');
  const last = text.lastIndexOf('}');
  if (first !== -1 && last !== -1 && last > first) return text.slice(first, last + 1);
  return text;
}

export function parseCardJson(text) {
  let obj;
  try {
    obj = JSON.parse(stripFence(text).trim());
  } catch {
    throw new Error('模型没返回有效 JSON，换个描述再试一次');
  }
  const notes = obj.notes || {};
  const visual = obj.visual || {};
  return {
    perfumeName: obj.perfumeName || '',
    family: obj.family || '',
    notes: {
      top: Array.isArray(notes.top) ? notes.top : [],
      mid: Array.isArray(notes.mid) ? notes.mid : [],
      base: Array.isArray(notes.base) ? notes.base : [],
    },
    keyMaterials: Array.isArray(obj.keyMaterials) ? obj.keyMaterials : [],
    visual: {
      palette: Array.isArray(visual.palette) && visual.palette.length ? visual.palette : DEFAULT_PALETTE,
      motif: visual.motif || '',
      texture: visual.texture || '',
      mood: visual.mood || '',
    },
    caption: obj.caption || '',
    ascii: typeof obj.ascii === 'string' && obj.ascii.trim() ? obj.ascii : '  ~  ~  ~\n (no ascii)\n  ~  ~  ~',
  };
}
```

```js
function extractText(raw) {
  return raw?.choices?.[0]?.message?.content ?? raw?.content?.[0]?.text ?? '';
}

export async function callLLM({ modelId, messages, config, fetchImpl = globalThis.fetch }) {
  const model = config.models.find((m) => m.id === modelId);
  if (!model) throw new Error(`未知模型: ${modelId}`);

  const apiKey = process.env[config.gateway.envKey];
  if (!apiKey) throw new Error(`缺少环境变量 ${config.gateway.envKey}`);

  const baseUrl = process.env[config.gateway.envBaseUrl] || config.gateway.defaultBaseUrl;

  const res = await fetchImpl(baseUrl + model.endpoint, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${apiKey}` },
    body: JSON.stringify({ model: modelId, messages, max_tokens: 8000 }),
  });

  if (!res.ok) {
    throw new Error(`LLM 调用失败 ${res.status}: ${await res.text()}`);
  }
  const raw = await res.json();
  return { text: extractText(raw) };
}
```

```js
import { buildMessages } from './prompt.js';
import { parseCardJson } from './parse.js';

function readBody(req) {
  return new Promise((resolve) => {
    let data = '';
    req.on('data', (c) => (data += c));
    req.on('end', () => resolve(data));
  });
}
function sendJson(res, code, obj) {
  const body = JSON.stringify(obj);
  res.writeHead(code, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(body);
}

export function createHandler({ config, callLLMImpl }) {
  return async function handler(req, res) {
    try {
      if (req.method === 'GET' && req.url === '/config') {
        return sendJson(res, 200, { models: config.models });
      }
      if (req.method === 'POST' && req.url === '/generate') {
        const body = JSON.parse((await readBody(req)) || '{}');
        const input = (body.input || '').trim();
        if (!input) return sendJson(res, 400, { error: '先写点香味描述' });
        const { text } = await callLLMImpl({
          modelId: body.model || config.models[0].id,
          messages: buildMessages(input),
          config,
        });
        return sendJson(res, 200, parseCardJson(text));
      }
      sendJson(res, 404, { error: 'not found' });
    } catch (e) {
      sendJson(res, 500, { error: String(e.message || e) });
    }
  };
}
```

```js
import http from 'node:http';
import fs from 'node:fs';
import path from 'node:path';
import { exec } from 'node:child_process';
import { agentDir } from './paths.js';
import { createHandler } from './app.js';
import { callLLM } from './llm.js';

const DIR = agentDir();
const WEB = path.join(DIR, 'web');
const PORT = Number(process.env.PORT ?? 4322);

function loadEnv() {
  const f = path.join(DIR, '.env');
  if (!fs.existsSync(f)) return;
  for (const line of fs.readFileSync(f, 'utf8').split('\n')) {
    const m = line.match(/^\s*([A-Z0-9_]+)\s*=\s*(.*)\s*$/);
    if (m && !process.env[m[1]]) process.env[m[1]] = m[2];
  }
}
loadEnv();

const config = JSON.parse(fs.readFileSync(path.join(DIR, 'config.json'), 'utf8'));
const api = createHandler({ config, callLLMImpl: callLLM });

const MIME = { '.html': 'text/html; charset=utf-8', '.js': 'text/javascript; charset=utf-8', '.css': 'text/css; charset=utf-8' };

const server = http.createServer((req, res) => {
  if (req.url === '/config' || req.url === '/generate') return api(req, res);
  // 静态
  const rel = req.url === '/' ? '/index.html' : req.url.split('?')[0];
  const file = path.join(WEB, rel);
  if (file.startsWith(WEB) && fs.existsSync(file) && fs.statSync(file).isFile()) {
    res.writeHead(200, { 'Content-Type': MIME[path.extname(file)] || 'application/octet-stream' });
    return res.end(fs.readFileSync(file));
  }
  res.writeHead(404); res.end('not found');
});
```

```js
// 真实 Risograph 油墨色板子集
export const RISO_INKS = ['#FF48B0', '#0078BF', '#FFE800', '#00A95C', '#FF6C2F', '#765BA7', '#000000'];

function hexToRgb(hex) {
  const m = /^#?([0-9a-f]{6})$/i.exec(String(hex).trim());
  if (!m) return null;
  const n = parseInt(m[1], 16);
  return [(n >> 16) & 255, (n >> 8) & 255, n & 255];
}

export function nearestInk(hex) {
  const rgb = hexToRgb(hex);
  if (!rgb) return RISO_INKS[0];
  let best = RISO_INKS[0], bestD = Infinity;
  for (const ink of RISO_INKS) {
    const [r, g, b] = hexToRgb(ink);
    const d = (r - rgb[0]) ** 2 + (g - rgb[1]) ** 2 + (b - rgb[2]) ** 2;
    if (d < bestD) { bestD = d; best = ink; }
  }
  return best;
}

export function risoSvg(card) {
  const W = 600, H = 800;
  const palette = (card.visual?.palette || [])
    .map(nearestInk)
    .filter(Boolean);
  const inks = palette.length ? palette : [RISO_INKS[0]];
  const title = [card.perfumeName, card.family].filter(Boolean).join(' · ');

  const defs = inks.map((ink, i) => `
    <pattern id="dot${i}" width="8" height="8" patternUnits="userSpaceOnUse">
      <circle cx="2" cy="2" r="2" fill="${ink}" />
    </pattern>`).join('');

  // 套色层：每层轻微偏移模拟套色错位
  const layers = inks.map((ink, i) => {
    const dx = (i - inks.length / 2) * 3;
    const dy = (i % 2 ? 1 : -1) * 2;
    const r = 120 + i * 40;
    return `<circle cx="${300 + dx}" cy="${340 + dy}" r="${r}" fill="url(#dot${i})" opacity="0.75" />`;
  }).join('');

  return `<svg xmlns="http://www.w3.org/2000/svg" width="${W}" height="${H}" viewBox="0 0 ${W} ${H}">
  <defs>${defs}</defs>
  <rect width="${W}" height="${H}" fill="#f4f1ea" />
  ${layers}
  <text x="40" y="${H - 60}" font-family="monospace" font-size="28" fill="#111">${escapeXml(title)}</text>
  <text x="40" y="${H - 30}" font-family="monospace" font-size="14" fill="#555">${escapeXml(card.caption || '')}</text>
</svg>`;
}

function escapeXml(s) {
  return String(s).replace(/[<>&]/g, (c) => ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
}
```

```js
import { asciiCard } from './ascii.js';
import { risoSvg } from './riso.js';

const $ = (id) => document.getElementById(id);
let current = null;

async function loadModels() {
  const { models } = await (await fetch('/config')).json();
  $('model').innerHTML = models.map(m => `<option value="${m.id}">${m.label}</option>`).join('');
}

async function generate() {
  const input = $('input').value.trim();
  if (!input) { $('status').textContent = '先写点香味描述'; return; }
  $('status').textContent = '生成中…'; $('gen').disabled = true;
  try {
    const res = await fetch('/generate', {
      method: 'POST', headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ input, model: $('model').value }),
    });
    const data = await res.json();
    if (!res.ok) throw new Error(data.error || '生成失败');
    current = data;
    renderCard(data);
    $('status').textContent = '';
  } catch (e) {
    $('status').textContent = String(e.message || e);
  } finally {
    $('gen').disabled = false;
  }
}

function renderCard(card) {
  $('front').innerHTML = risoSvg(card);
  $('back').innerHTML = `<pre>${escapeHtml(asciiCard(card))}</pre>`;
  $('card').classList.remove('flipped');
}

function escapeHtml(s) {
  return String(s).replace(/[<>&]/g, (c) => ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
}

async function exportPng() {
  if (!current) return;
  const flipped = $('card').classList.contains('flipped');
  const canvas = document.createElement('canvas');
  canvas.width = 600; canvas.height = 800;
  const ctx = canvas.getContext('2d');
  if (!flipped) {
    // 正面 Riso：SVG → image → canvas
    const svg = risoSvg(current);
    const img = new Image();
    const blob = new Blob([svg], { type: 'image/svg+xml' });
    const url = URL.createObjectURL(blob);
    await new Promise((r) => { img.onload = r; img.src = url; });
    ctx.drawImage(img, 0, 0, 600, 800);
    URL.revokeObjectURL(url);
  } else {
    // 反面 ASCII：画等宽文本
    ctx.fillStyle = '#f4f1ea'; ctx.fillRect(0, 0, 600, 800);
    ctx.fillStyle = '#111'; ctx.font = '12px monospace';
    asciiCard(current).split('\n').forEach((line, i) => ctx.fillText(line, 24, 36 + i * 15));
  }
  canvas.toBlob((b) => {
    const a = document.createElement('a');
    a.href = URL.createObjectURL(b);
    a.download = `${(current.perfumeName || 'roma')}-${flipped ? 'ascii' : 'riso'}.png`;
    a.click();
    URL.revokeObjectURL(a.href);
  });
}

$('gen').onclick = generate;
$('flip').onclick = () => $('card').classList.toggle('flipped');
$('card').onclick = () => $('card').classList.toggle('flipped');
$('export').onclick = exportPng;
$('showNotes').onchange = (e) => document.body.classList.toggle('show-notes', e.target.checked);

loadModels();
```
