# Tools 工具集

SIRIUS-ATEAM 收纳的独立小工具,供团队设计/研发流程按需取用。与 `agents/`(协作 Agent)、`scripts/`(系统运维脚本)分开管理:这里放**能独立运行、面向具体场景的辅助工具**。

## 工具清单

| 工具 | 作用 | 形态 | 来源 |
|------|------|------|------|
| [event-bubble-guard](./event-bubble-guard/) | 配合 Figma「HTML to Design」扩展使用:点击页面顶部 Figma 工具栏时,不再误关页面上已打开的下拉/抽屉/弹层,便于选中这些浮层元素 | Chrome 扩展 | 原桌面独立工具,2026-10 并入统一管理 |

## 维护约定

- 新增工具:在本目录建子文件夹,附各自 README,并在上表登记一行。
- 工具若成长为需要独立迭代的项目,再抽成独立仓库(参考 siri.sh → siri-tools 的做法)。
