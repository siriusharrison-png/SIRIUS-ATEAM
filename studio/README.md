# Studio

用于收纳团队里的展示性质、分享性质、临时存档和思考记录文件。

## 目录约定

| 目录 | 用途 |
|---|---|
| `showcase/` | 展示页、分享页、可对外查看的材料 |
| `notes/` | 临时存档、优化记录、思考笔记 |
| `archive/` | 已明确归档的历史资产 |

## 使用原则

- 不属于主业务链路，但仍需要保留的文件，优先放入这里
- 展示页和分享页必须在这里有明确分类
- 临时记录不直接放在仓库根目录
- 如果文件开始进入主流程，再迁回对应的业务目录
