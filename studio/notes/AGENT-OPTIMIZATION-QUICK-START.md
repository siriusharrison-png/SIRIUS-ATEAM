## 核心解决方案

### P0：激活 hub.json（3-4 天）

**目标**：从静态模板 → 实时协作中枢

**行动**：
1. 创建 `agents/lib/hub_manager.py` - 原子性读写工具
2. 修改 3 个 Agent 脚本 - 完成任务后更新 hub.json
3. 重新初始化 hub.json - 当前状态

**验收**：
- ✅ lastSeen 为今日日期
- ✅ Agent 完成任务自动更新

### P1：规则版本化（2-3 天）

**目标**：从固定规则 → 清晰演进

**行动**：
1. 创建 `RULES-HISTORY.md` - 版本清单
2. 创建 `RULES-PROPOSAL-TEMPLATE.md` - 建议模板
3. 修改 `RULES.md` - 添加版本和更新流程

**验收**：
- ✅ RULES.md v1.1.0 版本清晰
- ✅ 有规则更新流程文档

### P1：可观测性（3-4 天）

**目标**：从"看不见" → "全可观测"

**行动**：
1. 创建 `agents/lib/agent_logger.py` - JSON 行日志
2. 修改 3 个工作流 - 移除 continue-on-error，添加日志
3. 创建日志聚合页面 - `.claude/logs/dashboard.html`

**验收**：
- ✅ 工作流失败 24 小时内有飞书通知
- ✅ 所有日志 JSON 格式存储
